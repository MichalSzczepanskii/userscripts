# userscripts

Personal Tampermonkey userscripts, used on more than one machine (macOS and Windows).

## Language

**Hosted script**:
The published build of a script, installed from its public URL for everyday use on every machine.
_Avoid_: release, prod script

**Stub**:
A header-only script that loads the local build from disk, installed in place of the hosted script only while developing it on that machine.
_Avoid_: dev script, loader
